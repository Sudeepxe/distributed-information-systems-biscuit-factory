# Distributed Information Systems – Biscuit Factory Data Modelling Project

## Overview

This project was developed for the Distributed Information Systems module.

The objective was to design and implement the same business scenario using three different data representation approaches:

- Relational Database (SQL)
- XML + XQuery
- Semantic Ontology (OWL/RDF) + SPARQL

The system models a biscuit manufacturing company including departments, employees, facilities, distributors, ingredients, production teams, roles, and biscuit products.
